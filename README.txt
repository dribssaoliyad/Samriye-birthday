SAMRI & OLI — BIRTHDAY SURPRISE WEBSITE
========================================

Files:
- index.html, style.css, script.js: the complete mobile-friendly website
- images/: photos reused from the earlier Samri & Oli memory website

PREVIEW LOCALLY
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. Internet is needed for Google Fonts; the rest of the app runs locally.

PUBLISH WITH NETLIFY (simple option)
1. Go to https://app.netlify.com/drop and sign in.
2. Extract this ZIP on your computer.
3. Drag the extracted folder (the folder with index.html directly inside it) into Netlify Drop.
4. Wait for Netlify to publish and copy the public address ending in netlify.app.
5. Open that URL on your phone to test it.

QR CODE
After you have the final public URL, create a QR code that points to that exact URL.
Do not use a local file path or the ZIP link as the QR destination.

CUSTOMIZATION
- Birthday date is set to October 27, 2026 in script.js and index.html.
- The gentle music button generates a simple original melody in the browser; it does not include copyrighted music.
- To add photos, put image files inside images/ and edit the photo cards in index.html to use those filenames.
- This is a static site. Anyone who has the public link can view it; don't publish photos you want to keep private.
